# Ashcrown — Boss Fantasy: The Coil Warden

**Owner:** Creative Director (fantasy) · Combat Designer (feel / frame data)  
**Slice:** First Playable · Emberveil Reach · Coilcrypt  
**Status:** LOCKED — aligned to Combat 2–3 phase template  
**Tone:** Ember / legacy (`TONE.md`)

---

## Fantasy one-liner

A Wake-forged guardian fused to a buried battery coil, feeding on Aether bleed. Binding gone wrong — not a demon, not a dragon. Choirbound call it a wound; Wakewrights call it an engine that remembered hunger.

---

## Aether vs Wake lean (LOCKED)

| Layer | Lean | Player read |
|-------|------|-------------|
| **Body / weapons / poise** | **Wake-primary** | Brushed metal, conduit ribs, glyph-etched armor; hard silhouette |
| **Arena hazards / Phase 2** | **Aether bleed** | Bioluminescent vents, conductive pools, heat/Focus pressure |
| **Phase 3 motif** | **Ash-light (legacy)** | Ember aftertaste + circlet fragment tease — glory after fire |

Do **not** split the fight into “magic half / gun half.” One creature; Wake frame, Aether wound.

## Phase template (Combat) ↔ fantasy map

| Phase | Combat template | Fantasy beat | Telegraph teaching |
|-------|-----------------|--------------|-------------------|
| **1** | Learn 2–3 tells | **Coil sentinel** — Warden still “on duty,” testing the intruder | Amber dodge sweeps (coil arm), blue-white blockable glyph slam, one soft ranged conduit spit |
| **2** | Unblockable **or** arena hazard | **Bleed surge** — coil cracks; Aether vents open (arena hazard primary; 1–2 red unblockable coil overloads) | Red unblockable = coil rupture; amber AoE = vent bloom. Hazard readable without particle-only tells |
| **3** | Enrage / poise windows | **Crown echo** — ash-light flare in the helm/circlet scar; brief enrage; poise windows to finish | Same color language; faster timing; silhouette stays Wake-metal, not particle soup |

**Unique drop:** **Ash-etched Circlet Fragment** — build tease toward Ashcrown; never the full relic in First Playable.

## VFX / art directives (phone-readable)

- Silhouette first: metal guardian + coil spine must read at Mid preset before glow detail.
- Telegraph colors stay Combat-locked: **amber dodge / blue-white block / red unblockable** — no competing rainbow schools on tells.
- Ember accents on hits and phase transitions; cool Aether on vents only.
- Forbidden: generic demon horns, particle-only attack tells, full-screen white flash spam.
